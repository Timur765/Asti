# ASTI — интернет-магазин одежды

Полноценный магазин: витрина, каталог с фильтрами, карточки товаров, корзина, заказы в Telegram, защищённая админ-панель, PWA для iPhone.

**Стек (всё бесплатно на старте):**

| Что | Чем |
|---|---|
| Фронтенд | чистый HTML/CSS/JS, без сборки |
| База данных | Supabase Postgres (облако) |
| Фото товаров | Supabase Storage (облако, публичный бакет `products`) |
| Авторизация админа | Supabase Auth + политики RLS |
| Заказы в Telegram | серверная функция `api/order.js` (Vercel) |
| Хостинг | Vercel |

## Структура

```
index.html  catalog.html  product.html  admin.html   страницы
css/style.css                                         дизайн
js/config.js                                          ← ваши ключи Supabase
js/common.js  index.js  catalog.js  product.js  admin.js
api/order.js                                          отправка заказа в Telegram (сервер)
supabase/schema.sql                                   таблицы, права, хранилище, 9 карточек Pinduoduo
manifest.webmanifest  sw.js  icons/                   PWA
vercel.json                                           заголовки безопасности
```

## Шаг 1. База данных (Supabase)

1. Зарегистрируйтесь на <https://supabase.com> → **New project** (регион — ближайший, запомните пароль БД).
2. Откройте **SQL Editor → New query**, вставьте **весь** файл `supabase/schema.sql` → **Run**.
   Создадутся таблицы, политики безопасности, бакет для фото и 9 карточек Pinduoduo.
   Запускать нужно один раз (повторный запуск безопасен: дубликаты карточек не создаются).
3. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
4. Вставьте их в `js/config.js`:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJ...',
   ```
   anon-ключ публичный по дизайну: записывать данные он не позволяет, это обеспечивают политики RLS.
   **Ключ `service_role` никогда не вставляйте в сайт.**

## Шаг 2. Администратор

1. **Authentication → Users → Add user → Create new user**: укажите email и сильный пароль (поставьте «Auto Confirm User»).
2. **SQL Editor** — сделайте этого пользователя администратором (подставьте свой email):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'admin@example.com';
   ```
3. **Authentication → Sign In / Providers → Email**: выключите **Allow new users to sign up** — чтобы никто посторонний не мог регистрироваться.
4. Админ-панель: `https://ваш-сайт/admin.html`. Вход по email и паролю.

Права проверяются **в самой базе**: записывать товары и фото может только пользователь из таблицы `admins`. Подделка интерфейса в браузере ничего не даст.

## Шаг 3. Telegram-бот для заказов

Сайт не может писать в Telegram напрямую (пришлось бы раскрыть токен), поэтому заказы отправляет бот через серверную функцию.

1. В Telegram откройте **@BotFather** → `/newbot` → получите **токен** бота.
2. Определите **chat id**, куда бот будет присылать заказы:
   - **Если `@ast1_shop` — канал:** добавьте бота в канал как администратора с правом публикации. Chat id канала — `@ast1_shop` (для публичного канала подойдёт сам username) либо число вида `-100…`.
   - **Если нужны личные сообщения:** владелец магазина должен один раз нажать **Start** у своего бота. Затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет `"chat":{"id":123456789,…}`. Это и есть chat id.
3. Если автоматическая отправка по какой-то причине не сработает, покупатель увидит кнопку «Скопировать и открыть Telegram» — заказ не потеряется.

## Шаг 4. Публикация (Vercel)

**Вариант A — через GitHub (рекомендуется):**
1. Создайте репозиторий на GitHub и загрузите содержимое папки проекта (`js/config.js` с вашими ключами можно коммитить — они публичные).
2. На <https://vercel.com> → **Add New → Project** → выберите репозиторий. Framework Preset — **Other**, сборка не нужна.
3. **Settings → Environment Variables** добавьте:

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `TELEGRAM_CHAT_ID` | chat id из шага 3 |
   | `SUPABASE_URL` | тот же URL проекта |
   | `SUPABASE_ANON_KEY` | тот же anon-ключ |

4. **Deploy** (после добавления переменных — сделайте Redeploy).

**Вариант B — консоль:**
```bash
npm i -g vercel
cd asti
vercel            # первый деплой, ответьте на вопросы
vercel env add TELEGRAM_BOT_TOKEN
vercel env add TELEGRAM_CHAT_ID
vercel env add SUPABASE_URL
vercel env add SUPABASE_ANON_KEY
vercel --prod
```

**Свой домен:** Vercel → Settings → Domains. HTTPS выдаётся автоматически (он обязателен для PWA).

> Сайт нужно размещать в **корне домена** (не в подпапке), иначе `/api/order` и service worker не найдут друг друга.

## Локальный запуск

```bash
npm i -g vercel
cd asti
vercel dev
```
Создайте файл `.env` рядом с `vercel.json` с четырьмя переменными из таблицы выше. Сайт откроется на `http://localhost:3000`. Только для просмотра витрины без заказов хватит и `npx serve`.

## Установка на iPhone (PWA)

1. Откройте сайт в **Safari**.
2. Нажмите **«Поделиться»** → **«На экран “Домой”»** → **Добавить**.
3. Иконка ASTI появится на главном экране, сайт откроется во весь экран, как приложение. На iPhone сайт сам подскажет это при первом посещении.

## Работа с админ-панелью

- **Добавить товар:** «+ Добавить товар» → название, категория, цена, остаток, статус, описание, размеры (быстрые пресеты для одежды и обуви), цвета, фото. Фото сжимаются в браузере до 1800 px и загружаются в облако; первое фото — главное (★ делает фото главным).
- **Быстрые правки:** цену, остаток, статус и «на сайте» можно менять прямо в списке — сохраняется мгновенно.
- **Статусы:** «В наличии» (покупатель не может заказать больше остатка), «Предзаказ», «Нет в наличии». Товар с остатком 0 и статусом «В наличии» автоматически показывается как «Нет в наличии».
- **Удаление** товара удаляет и его фото из хранилища.
- **Карточки Pinduoduo** (9 шт.): созданы с пометкой «Фото и характеристики уточняются», без цены и характеристик — ничего не выдумано. Когда данные появятся, откройте карточку → «Изменить», загрузите фото, укажите цену, размеры и описание; при желании снимите галочку «Карточка Pinduoduo» — она превратится в обычный товар. Название «Товар Pinduoduo №N» тоже можно заменить.
- Изменения сразу видны в каталоге и сохраняются в облачной базе.

## Безопасность

- Токен Telegram хранится только в переменных окружения Vercel.
- Цены и наличие при заказе **пересчитываются на сервере** по данным базы — подменить цену в браузере нельзя.
- На запись в базу и хранилище действуют политики RLS (только таблица `admins`).
- Защита формы заказа: ограничение частоты запросов, скрытое поле-ловушка для ботов, экранирование данных в Telegram-сообщении.
- Админ-страница закрыта от индексации (`noindex`), не кэшируется service worker'ом.
- Рекомендуется включить 2FA в аккаунтах Supabase и Vercel и использовать длинный пароль администратора.

## Ограничения и идеи для развития

- Остаток **не списывается автоматически** после заказа — менеджер подтверждает заказ и меняет остаток в админке.
- Остаток общий на товар (не по каждому размеру).
- Онлайн-оплаты нет: оплату и доставку согласует менеджер в Telegram.
- Условия доставки и оплаты на сайте намеренно не указаны — добавьте их в блок «О магазине» (`index.html`), когда определитесь.
